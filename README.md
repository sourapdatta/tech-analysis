# tech-analysis

Static HTML published with GitHub Pages.

**Live site:** https://sourapdatta.github.io/tech-analysis/

## Adding a page

1. Drop any `.html` file in this folder (subfolders are fine too).
2. Run `./sync.sh` — it rebuilds `index.html` and pushes to `main`.
3. GitHub Pages redeploys in ~30-60 seconds.

A file at `foo.html` is served at
`https://sourapdatta.github.io/tech-analysis/foo.html`, and
`reports/bar.html` at `.../tech-analysis/reports/bar.html`.

## Notes

- Everything here is **public**. Don't commit anything you wouldn't post online.
- `index.html` is generated by `sync.sh` — edit `build-index.sh` to change its look,
  not `index.html` itself.
- `.nojekyll` tells Pages to serve files verbatim (no Jekyll build), which keeps
  filenames starting with `_` working.
